The trader lives through each past day in order: morning brief, research, plans, check-ins, the close, then a review that rewrites its playbook before the next day. It only ever sees what was known at that moment. Claude runs use the model and effort from the top bar: about 7 calls per day, roughly 1–2 minutes a day with Sonnet 5.5 (longer with Opus or higher effort).


    

    

      
How to tell whether it works

      
    
        
  1. Run the free gap-and-go control over the whole range. That is the bar to beat.
    2. 
        
  2. Run Claude, learning over the same days, then the same with learning off. Select runs and press Compare: it pairs them day by day.
    3. 
        
  3. In each report, check Is it learning? (later blocks should beat earlier ones) and the priced check-in interventions.
    4. 
        
  4. Backtests only reach back about 60 days, so treat them as development. The real test is live paper trading going forward, on days nothing was tuned on. Look for 100+ trades with the average-R interval above zero.
